# Play with NLP

This repository contains various NLP projects that demonstrate the application of deep learning and Transformer-based architectures in different NLP tasks. Each project is organized in individual folders.

## Projects

### 1. Machine Translation System
- **Description:** Built a neural machine translation model to convert Bangla text to English and vice versa using Transformer-based architectures.
- **Tech Stack:** Python, TensorFlow, Transformers, Seq2Seq
- **Folder:** `Machine_Translation_System`
- [GitHub Link](#)

### 2. Text Summarization using Transformers
- **Description:** Developed an extractive and abstractive text summarization system using pre-trained Transformer models like BART and T5.
- **Tech Stack:** Python, PyTorch, Hugging Face Transformers
- **Folder:** `Text_Summarization`
- [GitHub Link](#)

### 3. Text-to-Speech (TTS) System
- **Description:** Implemented a deep learning-based Bangla text-to-speech system using Tacotron and WaveGlow models for natural speech synthesis.
- **Tech Stack:** Python, TensorFlow, Tacotron, WaveGlow
- **Folder:** `Text_to_Speech`
- [GitHub Link](#)

### 4. Conversational AI Chatbot
- **Description:** Developed a chatbot capable of handling multi-turn conversations using Transformer-based architectures like DialoGPT and Rasa.
- **Tech Stack:** Python, Rasa, Transformers, NLP
- **Folder:** `Conversational_AI_Chatbot`
- [GitHub Link](#)

### 5. Sentiment Analysis System
- **Description:** Built a sentiment analysis model to classify text into positive, negative, and neutral sentiments using deep learning techniques.
- **Tech Stack:** Python, TensorFlow, NLTK, Transformers
- **Folder:** `Sentiment_Analysis`
- [GitHub Link](#)

### 6. Document Similarity Detection
- **Description:** Developed a document similarity system using NLP techniques to measure the semantic similarity between texts.
- **Tech Stack:** Python, SpaCy, Gensim, Transformers
- **Folder:** `Document_Similarity_Detection`
- [GitHub Link](#)

## How to Use
1. Clone this repository:
   ```bash
   git clone https://github.com/hm-badhon/Play-with-NLP.git
   ```

3. Follow the instructions provided in each project's `README.md` file.
